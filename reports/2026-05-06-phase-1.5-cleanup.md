## What was wrong

`docs/TODO.md` marked migrations 003 (`value_tool`) and 004 (`listings_cache`) as `[x]` shipped, but `mcp__Supabase__list_tables` confirmed neither was actually applied to the production project. Specifically:

- `valuation_cache` — missing. `/value` was hitting RentCast direct on every query (no cache). Stephen's Vercel monthly cost calculation in ROADMAP § 4.1 assumed cache hits would dominate; without the table, every visitor blew through RentCast call quota.
- `cma_requests` — missing. Every CMA form submission went through `/api/value/request-cma` and silently failed the Supabase insert. **The route did not error to the user** — the `lib/hubspot.ts` and `lib/resend.ts` wrappers also fail gracefully — so leads from `/value` likely landed in HubSpot when `HUBSPOT_PRIVATE_APP_TOKEN` was set, but were not recorded as the source of truth in Supabase. With the token unset (current state per TODO), CMA leads are not captured anywhere.
- `listings_cache` — missing. Currently irrelevant because MLS Grid key is also unset, but Phase 2 work shouldn't proceed on top of an inconsistent schema state.
- `valuation_requests` — present from migration 001 but orphaned. It backed the v1 `/home-valuation` page Stephen approved deleting in Phase 0. 0 rows. Superseded by `cma_requests`.

## Note on `spatial_ref_sys`

The Supabase MCP advisory flags `public.spatial_ref_sys` as having RLS disabled. **This is the standard PostGIS reference table** and is supposed to be world-readable — enabling RLS on it would break PostGIS spatial queries (the table backs the SRID lookups every PostGIS function depends on). Recommend leaving as-is; the data is reference-only spatial reference system definitions, not user data.

If Stephen wants to silence the advisory, the standard approach is:
```sql
ALTER TABLE public.spatial_ref_sys ENABLE ROW LEVEL SECURITY;
CREATE POLICY "spatial_ref_sys_public_read" ON public.spatial_ref_sys FOR SELECT USING (true);
```
(Public read only, no writes — matches PostGIS expectations.) Surfaced for Stephen's call; not applied in Phase 1.5.
